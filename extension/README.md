# PriceWatcher Chrome / Edge Extension

A lightweight Manifest V3 extension to track products from Amazon, Flipkart, Myntra, Ajio, Meesho, and Westside with 1 click.

## How to Install (Takes 10 Seconds):
1. Open Google Chrome or Microsoft Edge and navigate to `chrome://extensions`.
2. Turn ON **Developer mode** (toggle switch in the top-right corner).
3. Click **Load unpacked** (top-left button).
4. Select the `extension` folder located inside this project directory (`Ecommerce tracker/extension`).
5. Pin the extension to your toolbar.

## How to Use:
1. Open any product page on Amazon, Flipkart, Myntra, Ajio, Westside, or Meesho.
2. Click the **PriceWatcher Companion** icon in your browser toolbar.
3. (Optional) Enter your desired target price.
4. Click **Track This Product**! The item is instantly added to your dashboard.
